Roblox Server Automation Tool
This project is a Python-based automation tool for configuring local Roblox private servers. Currently, it supports disabling and renaming servers, with potential for future feature expansions.

Features:
- Automates disabling and renaming Roblox private servers.
- Simple setup with reference images provided.
- Easy to modify or expand by updating images or adding new actions.

Requirements & Limitations
Due to the reliance on PyAutoGUI, the tool has several limitations:
- Operating System: Windows 10 is recommended. Ensure Windows display scaling is set to 100%.
- Browser: Designed for Google Chrome with zoom set to 100%. Any changes require updating the reference images accordingly.
- Roblox Compatibility: Only supports the Roblox browser version.

Images: A downloadable ReferenceImages folder is included with the images used by the tool. 
If an image fails, you can easily create your own by taking a screenshot and naming it exactly as in the program.
